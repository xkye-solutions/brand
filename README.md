# @xkye/brand

> **Read-only Mirror.** This is maintained in Xkye Solutions' private monorepo and split here with its history. Changes made here are overwritten, so please don't open issues or pull requests.

Xkye's brand assets and tokens, consumed by the Official Website and the case-study kit.

- `assets/`: logos, marks, favicons, app icons, avatar (from `xkye-brand-assets-official.zip`). Never retype the wordmark; below 120px use the mark.
- `assets/social-card-1200x630.svg` / `.png`: the Official Website's social card, built from the logo and mark paths. The PNG is exported from the SVG at 1200×630 with Montserrat loaded; re-export it whenever the SVG or the hero line changes.
- `tokens.css`: palette, gradient, and type scale as CSS custom properties (from `XKYE-Brand-Kit-v2.html`).

Fonts (Montserrat 300–700, JetBrains Mono 400–500, both OFL on Google Fonts) are named in the tokens but not loaded here.
